# Lesson_6# Lesson_6

Проект содержит скрипты для изучения циклов `for`, словарей (`dict`), а также GUI-приложения на Tkinter: опрос с Radiobutton, список продуктов, дни недели и работа со шрифтами/цветами.

## Файлы проекта

- `Home work/main.py` # Демонстрация шрифтов и цветов (фамилия и имя)
- `Home work/main_1.py` # Список дней недели с возможностью удаления
- `Home work/main_2.py` # Список продуктов (добавление и очистка всего списка)
- `main_3.py` # Цикл for по списку фруктов
- `main_4.py` # Цикл for с range(0, 5)
- `main_5.py` # Цикл for с выводом "Привет, Кодики" 5 раз
- `main_6.py` # Цикл for для подсчёта суммы от 1 до 20
- `main_7.py` # Цикл for с условием: произведение чётных чисел от 1 до 14
- `main_8.py` # Словарь с данными пользователя (имя, фамилия, возраст)
- `main_9.py.py` # Словарь с информацией о фильмах
- `main_10.py` # GUI-приложение "Опрос" с несколькими вопросами и Radiobutton
