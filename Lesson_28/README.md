# Lesson_28

Проект содержит скрипты для изучения обработки естественного языка (NLU): наивный байесовский классификатор для распознавания интентов текста (приветствие, вопрос, прощание, шутка, настроение, погода, комплимент) и генератор текста на основе марковской цепи (создание случайных историй по обученным моделям слов).

## Файлы проекта

- `Home work/main.py` # Naive Bayes классификатор (14 текстов, 7 категорий, предсказание с выводом категории)
- `Home work/main_1.py` # Naive Bayes классификатор (расширенный набор данных, 7 категорий)
- `Home work/main_2.py` # Naive Bayes классификатор с вариативными ответами (случайный выбор из списка)
- `main_3.py` # Генератор текста на основе марковской цепи (обучение на одном из 3 текстов, генерация по длине)
