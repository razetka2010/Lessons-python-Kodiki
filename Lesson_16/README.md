# Lesson_16# Lesson_16

Проект содержит двух VK-ботов: один с функцией отправки изображений (медиа-вложение), другой — с клавиатурой и расширенным функционалом (информация о проектах, шуточная религия "Камазианство", описание "Пога" и случайный выбор команды).

## Файлы проекта

- `bot.py` # Бот с медиа (команда /vk отправляет фото)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `Home work/bot.py` # Бот с клавиатурой (команды: Помощь, Знание Севера, Знание Севера VPN, Камаз, Пог, Случайно)
- `Home work/config.py` # Файл с токеном для второго бота (токен скрыт)
