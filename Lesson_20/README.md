# Lesson_20

Проект содержит VK-бота на библиотеке vkbottle с расширенным функционалом: факты, цитаты, шутки, настроение, эмодзи, генератор никнеймов и другие команды, а также JSON-файл с данными и скрипт для работы с API цитат.

## Файлы проекта

- `bot.py` # Бот на vkbottle (команды: /start, /stop, /help, /emoji, /dice, /coin, /8ball, /fact, /quote, /joke_local, /math, /mood)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `data.json` # JSON-файл с фактами, настроениями и цитатами
- `main.py` # Скрипт для тестирования API цитат (forismatic.com)
- `Home work/bot.py` # Вторая версия бота (факты, цитаты, шутки, настроение, эмодзи без JSON)
- `Home work/config.py` # Файл с токеном для второго бота (токен скрыт)
