# Lesson_13

Проект содержит VK-бота, написанного на Python с использованием библиотеки vk_api. Бот отвечает на команды пользователей в личных сообщениях, предоставляя информацию об авторе, ссылки на проекты и сторонние сервисы.

## Файлы проекта

- `bot.py` # Основной код VK-бота (обработка команд: /start, /help, /znaniesevera, /znanieseveravpn)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `Home work/bot.py` # Вторая версия бота (расширенное приветствие, информация об авторе, ссылки на GitHub и сайт)
- `Home work/config.py` # Файл с токеном для второй версии бота (токен скрыт)
