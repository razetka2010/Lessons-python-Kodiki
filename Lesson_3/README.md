# Lesson_3

Проект содержит пять Python-скриптов, демонстрирующих работу со списками, модулем `random`, а также GUI-приложения на Tkinter: генератор паролей и расширенный калькулятор.

## Файлы проекта
- `Home work/main.py` # Расширенный калькулятор (7 операций)
- `main_1.py` # Работа со списками (добавление, вставка, длина)
- `main_2.py` # Модуль random (выбор элемента и буквы)
- `main3.py` # Генератор паролей с GUI
