# Lesson_22

Проект содержит двух VK-ботов на библиотеке vkbottle: первый бот ведёт диалог с пользователем, запрашивая имя и возраст с сохранением в JSON-файл, второй — бот с обработкой ключевых слов (приветствие, прощание, благодарность, вопросы о боте и делах, время).

## Файлы проекта

- `bot.py` # Бот-анкета (команда /start, запрос имени и возраста, сохранение в new_user.json)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `Home work/bot.py` # Бот с обработкой текста (ключевые слова: привет, пока, спасибо, ты кто, как дела, время)
- `Home work/config.py` # Файл с токеном для второго бота (токен скрыт)
