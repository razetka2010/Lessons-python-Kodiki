# Lesson_14

Проект содержит VK-бота с расширенным функционалом: приветствие в зависимости от времени суток, вывод текущего времени, случайные новости и шутки.

## Файлы проекта

- `main.py` # Основной код VK-бота (команды: /start, /help, /about, /news, /joke, /time)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
