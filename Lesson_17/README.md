# Lesson_17

Проект содержит двух VK-ботов: игровой бот с тремя мини-играми (угадай число, угадай город по фото, правда или ложь) и бот для отправки мемов и случайных картинок с клавиатурой.

## Файлы проекта

- `bot.py` # Игровой бот (команда "игры" вызывает меню: 1, 2, 3)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `Home work/bot.py` # Бот с мемами (команды: мем, рандомная картинка, /start, /help)
- `Home work/config.py` # Файл с токеном для второго бота (токен скрыт)
