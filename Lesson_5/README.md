# Lesson_5

Проект содержит скрипты для изучения циклов `while`, условных операторов `if-elif-else`, а также GUI-приложения на Tkinter: демонстрация цветов и шрифтов, список дел и работа с `root.after()`.

## Файлы проекта

- `Home work/main.py` # Проверка числа (маленькое/большое)
- `Home work/main_1.py` # Цикл while: обратный отсчёт от 8 до 1
- `main_2.py` # Цикл while: обратный отсчёт от 100 до 0 с сообщением "Время вышло"
- `main_3.py` # Условия if-elif-else (температура)
- `main_4.py` # Демонстрация root.after() с рекурсивной задержкой
- `main_5.py` # Демонстрация цветов и шрифтов в Tkinter
- `main_6.py` # Приложение "Список дел" (добавление и удаление задач)
