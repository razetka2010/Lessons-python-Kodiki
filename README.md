## Примечание о файлах

**Важно:** В процессе работы над проектами некоторые изображения (`.jpg`, `.png`, `.gif`) и JSON-файлы были переименованы для удобства организации. В исходных скриптах могут встречаться ссылки на конкретные имена файлов, которые были изменены.

- **Изображения:** В уроках 8, 10, 11, 16, 17, 23 использовались локальные изображения (`1.png`, `2.gif`, `artempog.png`, `Krasota1.jpg`, `photo-...`), которые были переименованы или перемещены.
- **JSON-файлы:** В уроках 18, 19, 20, 21, 22, 23 использовались файлы (`users.json`, `data.json`, `1.json`, `2.json`, `new_user.json`, `data_homework.json`), имена некоторых из них были изменены.

Для корректной работы скриптов убедитесь, что пути к файлам в коде соответствуют актуальным именам файлов в вашей файловой системе.

## Основные технологии

| Технология | Назначение |
|------------|------------|
| `tkinter` | GUI-приложения (калькулятор, викторины, секундомер, список дел) |
| `PIL/Pillow` | Работа с изображениями (открытие, resize, thumbnail) |
| `scikit-learn` | Машинное обучение (регрессия, деревья решений, Naive Bayes, TF-IDF) |
| `opencv-python` | Компьютерное зрение (размытие, цветовые пространства, детекция лиц, движение) |
| `vkbottle` / `vk_api` | Создание VK-ботов (клавиатуры, кнопки, вложения) |
| `numpy`, `pandas` | Обработка данных (вспомогательно) |
