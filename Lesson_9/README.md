# Lesson_8

Проект содержит скрипты для изучения расчёта скидок с округлением (`round`), консольной викторины, GUI-викторины с подсчётом очков, а также работы с изображениями через библиотеку PIL.

## Файлы проекта

- `Home work/main.py` # Расчёт суммы скидки и итоговой цены (округление до 2 знаков)
- `Home work/main_1.py` # Консольная викторина (3 вопроса) с подсчётом процента правильных ответов
- `Home work/main_2.py` # GUI-викторина (3 вопроса) с Radiobutton, подсчётом очков и возможностью сыграть ещё раз
- `main_3.py` # Работа с изображениями через PIL (открытие, изменение размера, отображение в Tkinter)
- `1.png` # фотография
