# Lesson_12

Проект содержит два GUI-приложения на Tkinter: калькулятор с графическим интерфейсом (кнопки цифр и операций) и математическую викторину с примерами на сложение, вычитание, умножение, деление и десятичные дроби.

## Файлы проекта

- `main1.py` # Калькулятор с кнопками (цифры, +, -, *, /, =, очистка) и функцией eval()
- `main2.py` # Математическая викторина (9 вопросов) с Radiobutton, подсчётом очков и возможностью сыграть ещё раз
