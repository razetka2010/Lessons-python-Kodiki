# Lesson_11

Проект содержит скрипты для изучения работы с изображениями в Tkinter: отображение галереи из нескольких картинок в ряд, загрузка одного изображения из списка и создание слайдера с кнопками навигации.

## Файлы проекта

- `Home work/main.py` # Галерея из 6 изображений (3 JPG + 3 PNG), расположенных в два ряда по 3 картинки
- `Home work/main_1.py` # Загрузка и отображение первого изображения из списка (без навигации)
- `Home work/main_2.py` # Слайдер изображений с кнопками "Назад" и "Вперёд" (6 изображений)
- `1.jpg` # фотография
- `2.jpg` # фотография

- `4.png` # фотография
