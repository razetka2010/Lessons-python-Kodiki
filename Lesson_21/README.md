# Lesson_21

Проект содержит VK-бота на библиотеке vkbottle с обработкой естественного языка (приветствия, прощания, вопросы о делах, времени, "пог") и бота для работы с JSON-данными (вывод пользователей и товаров) и курсами валют с API ЦБ РФ.

## Файлы проекта

- `bot.py` # Бот с обработкой текста (ключевые слова: привет, пока, как дела, время, пог, помощь)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `Home work/1.json` # JSON-файл с данными пользователей и товаров
- `Home work/bot.py` # Бот для вывода данных из JSON и курсов валют (команды: /user, /products, /rates)
- `Home work/config.py` # Файл с токеном для второго бота (токен скрыт)
