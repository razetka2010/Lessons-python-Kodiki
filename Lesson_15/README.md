# Lesson_15

Проект содержит двух VK-ботов: один с клавиатурой и кнопками для удобного взаимодействия, другой — информационный бот с приветствием по времени суток и ссылками на проекты автора.

## Файлы проекта

- `bot.py` # Бот с клавиатурой (кнопки: Факт, Погода, Настроение, Музыка, Время, Помощь)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `Home work/bot.py` # Информационный бот (команды: /start, /help, /znaniesevera, /znanieseveravpn)
- `Home work/config.py` # Файл с токеном для второго бота (токен скрыт)
