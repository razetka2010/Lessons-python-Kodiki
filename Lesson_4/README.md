# Lesson_4

Проект содержит скрипты для изучения циклов `while`, условных операторов `if-elif-else`, а также GUI-приложения на Tkinter: секундомер, генератор случайных животных и рандомайзер никнеймов.

## Файлы проекта
- `Home work/main.py` # Список игр + random.choice()
- `Home work/main_1.py` # GUI: генератор "Животное дня"
- `Home work/main_2.py` # GUI: рандомайзер никнеймов (прилагательное + цвет + животное)
- `main.py_3` # Цикл while: от 0 до 5
- `main.py_4` # Цикл while: от 1 до 10
- `main.py_5` # Цикл while: обратный отсчёт яблок
- `main.py_6` # Условие if (пример с погодой)
- `main.py_7` # Условия if-elif (температура)
- `main.py_8` # GUI: секундомер (с кнопками Старт/Стоп и Сброс)
