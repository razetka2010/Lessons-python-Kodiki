# Lesson_18

Проект содержит двух VK-ботов: бот с памятью (сохраняет имя пользователя в JSON-файл) и игровой бот с четырьмя мини-играми (угадай число, угадай город по фото, правда или ложь, да или нет).

## Файлы проекта

- `bot.py` # Бот с памятью (команды: /start, /setname, /whoami, /help)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `main.py` # Скрипт для чтения и вывода данных из users.json
- `users.json` # JSON-файл с данными пользователей (имя, уровень, любимое занятие)
- `Home work/bot.py` # Игровой бот (команда "игры" вызывает меню: 1, 2, 3, 4)
- `Home work/config.py` # Файл с токеном для игрового бота (токен скрыт)
