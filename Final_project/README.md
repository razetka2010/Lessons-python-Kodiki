# Предсказатель оценок

Простое GUI-приложение на Python с использованием библиотеки Tkinter и машинного обучения (линейная регрессия), которое предсказывает оценку по количеству часов учёбы.

## Файлы проекта

- `main.py` — основное приложение с графическим интерфейсом
- `main_1.py` — генератор текста
- `data.json` — файл с данными для обучения (часы учёбы и оценки)
- `texts.json` — файл с данными для обучения (тексты)
