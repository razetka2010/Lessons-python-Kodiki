# Lesson_26

Проект содержит скрипты с использованием библиотеки scikit-learn для машинного обучения: линейная регрессия для предсказания баллов по часам обучения, а также деревья решений для классификации состояния питомца, уровня игрока и категории ученика.

## Файлы проекта

- `Home work/main.py` # Линейная регрессия (предсказание результата по часам занятий)
- `Home work/main_1.py` # Дерево решений (определение состояния питомца по сну и еде)
- `Home work/main_2.py` # Дерево решений (определение уровня игрока по часам игры и уровню)
- `main_3.py` # Линейная регрессия (обучение на данных с выбросами)
- `main_4.py` # Линейная регрессия (прогноз оценки по часам и выполнению ДЗ)
- `main_5.py` # Две модели регрессии (только игры и игры + победы)
