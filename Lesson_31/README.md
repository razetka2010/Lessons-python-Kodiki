# Lesson_31

Проект содержит скрипты для работы с компьютерным зрением: обнаружение лиц на статичном изображении и детекция движения с веб-камеры с одновременным распознаванием лиц.

## Файлы проекта

- `Home work/main.py` # Обнаружение лиц на изображении (Haar Cascade) с отрисовкой прямоугольников
- `main_1.py` # Детекция движения через веб-камеру (разница между кадрами) + обнаружение лиц
