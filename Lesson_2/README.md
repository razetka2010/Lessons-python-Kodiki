# Lesson_2

Проект содержит три простых GUI-приложения на Python с использованием библиотеки Tkinter. Каждое приложение демонстрирует разные возможности библиотеки: ввод данных, базовые вычисления и смену текста.

## Файлы проекта

- `Home work/main.py` # Приложение со сменой текста (шутка и возврат)
- `main1.py` # Приложение для ввода данных через поле ввода
- `main2.py` # Простой калькулятор (сложение и вычитание)
