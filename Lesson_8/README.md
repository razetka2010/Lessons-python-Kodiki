# Lesson_8

Проект содержит скрипты для изучения округления чисел (`round`), диалоговых окон (`messagebox`), а также полноценную игру-викторину с подсчётом очков, проверкой ответов и возможностью сыграть ещё раз.

## Файлы проекта

- `Home work/main.py` # Функция round() для округления чисел (45.6789 и 200/37)
- `Home work/main_1.py` # Демонстрация messagebox (showinfo и showwarning)
- `Home work/main_2.py` # Диалоговое окно askquestion с ответной реакцией (приветствие)
- `main_3.py` # Полноценная игра-викторина (3 вопроса, подсчёт очков, возможность сыграть ещё раз)
