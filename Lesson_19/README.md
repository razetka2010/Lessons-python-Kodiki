# Lesson_19

Проект содержит VK-бота, написанного на библиотеке vkbottle, с набором команд для развлечения (эмодзи, кубик, монетка, магический шар), а также JSON-файлы с данными о товарах и устройствах.

## Файлы проекта

- `bot.py` # Бот на vkbottle (команды: /start, /stop, /emoji, /dice, /coin, /8ball, /help)
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `Home work/1.json` # JSON-файл с товарами (iPhone, MacBook, видеокарта, клавиатура)
- `Home work/2.json` # JSON-файл с техникой (MacBook, Linux)
