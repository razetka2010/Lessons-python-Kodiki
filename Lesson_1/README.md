# Tkinter Fact Viewer

Простое GUI-приложение на Python с использованием библиотеки Tkinter, которое демонстрирует изменение текста метки при нажатии на кнопки.

## Файлы проекта

- `main_1.py` — базовая демонстрация: одна кнопка изменяет текст метки
- `main_2.py` — расширенная версия с двумя кнопками, каждая показывает интересный факт
