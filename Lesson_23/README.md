# Lesson_23

Проект содержит бота-портфолио "Знание Севера" с информацией о проектах Razetka, а также бота-анкету, который собирает данные о пользователе (имя, возраст, любимая игра, музыка, хобби) и сохраняет в JSON.

## Файлы проекта

- `bot.py` # Бот-портфолио (команды: /start, /help, /info, /projects, /znaniesevera, /todolist, /kamaz, /mycloud) с кнопками и вложениями
- `config.py` # Файл с токеном доступа VK API (токен скрыт)
- `Home work/1.json` # Пустой JSON-файл
- `Home work/bot.py` # Бот-анкета (команда /start, запрос имени, возраста, игры, музыки, хобби с сохранением в new_user.json)
- `Home work/config.py` # Файл с токеном для второго бота (токен скрыт)
