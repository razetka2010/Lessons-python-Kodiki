# Lesson_25

Проект содержит два скрипта с использованием библиотеки scikit-learn для машинного обучения: линейная регрессия для предсказания баллов по часам обучения и дерево решений для классификации уровня ученика.

## Файлы проекта

- `main.py` # Линейная регрессия (предсказание результата по часам обучения)
- `main_1.py` # Дерево решений (классификация ученика по часам и выполнению ДЗ)
