# Lesson_27

Проект содержит скрипты с использованием библиотеки scikit-learn: линейная регрессия для предсказания оценок по часам учёбы и уровня по играм/победам, а также наивный байесовский классификатор для обработки текста и ответов на сообщения.

## Файлы проекта

- `Home work/main.py` # Линейная регрессия (предсказание оценки по часам учёбы)
- `Home work/main_1.py` # Линейная регрессия (предсказание уровня по играм и победам)
- `Home work/main_2.py` # Линейная регрессия (пример с правильными данными)
- `main_3.py` # Naive Bayes классификатор (распознавание интентов текста: приветствие, вопрос, прощание, шутка и т.д.)
