# Lesson_29

Проект содержит скрипты для изучения работы с изображениями через библиотеку OpenCV (размытие, изменение цветовых пространств, изменение размера, обрезка) и генератор случайных историй из трёх частей.

## Файлы проекта

- `Home work/main.py` # Генератор случайных историй (сборка из трёх частей)
- `main_1.py` # GaussianBlur (размытие по Гауссу)
- `main_2.py` # Преобразование BGR в HSV
- `main_3.py` # Преобразование BGR в LAB
- `main_4.py` # Преобразование в оттенки серого, изменение размера, обрезка
- `main_5.py` # MedianBlur (медианное размытие)
- `main_6.py` # Преобразование BGR в RGB 
- `1.png` # фотография
