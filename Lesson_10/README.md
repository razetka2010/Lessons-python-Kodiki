# Lesson_10

Проект содержит скрипты для изучения работы с изображениями в Tkinter: отображение статичных картинок, GIF-анимация, добавление текста на изображения, а также полноценная фото-галерея с навигацией.

## Файлы проекта

- `Home work/main.py` # Отображение статичных изображений (PNG через PhotoImage и JPG через PIL)
- `Home work/main_1.py` # Анимация двух GIF-файлов одновременно с замедлением (subsample)
- `Home work/main_2.py` # Отображение изображений с подписями (текст поверх/под картинкой)
- `main_3.py` # Фото-галерея: открытие папки, навигация по изображениям (вперёд/назад) с иконками
