# Lesson_7

Проект содержит скрипты для изучения словарей (`dict`), циклов `for` с условиями, математического округления (`round`), а также GUI-приложения на Tkinter: демонстрация messagebox и игра-викторина.

## Файлы проекта

- `Home work/main.py` # Цикл for от 1 до 20: произведение чисел, кратных 3
- `Home work/main_1.py` # Словарь с информацией о книге (название, автор, год)
- `main_2.py` # Словарь пользователя (имя, возраст, пол, навыки) и список имён
- `main_3.py` # Демонстрация messagebox (инфо, предупреждение, ошибка, да/нет, вопрос)
- `main_4.py` # Функция round() для округления чисел
- `main_5.py` # GUI-приложение "Игра викторина" с вопросами и Radiobutton
